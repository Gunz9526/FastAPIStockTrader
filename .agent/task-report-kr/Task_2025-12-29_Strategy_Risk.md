# 작업 보고서: 전략 및 리스크 관리 구현

**날짜**: 2025-12-29
**작업**: TA-Lib 및 리스크 매니저 통합

## 요약
트레이딩 시스템의 지능과 안전성을 강화했습니다. `TA-Lib` (v0.6.8)을 도입하여 기술적 분석 피처를 생성하고, `RiskManager`를 통해 자본 관리 및 손익절 전략을 강제했습니다.

## 변경 내역
### 피처 엔지니어링 (`app/ml/features.py`)
- **TA-Lib 통합**: `add_technical_indicators` 메서드 구현.
- **지표**: RSI, MACD, Bollinger Bands, SMA, EMA, ATR 등 주요 지표 자동 계산.
- **데이터 처리**: 지표 계산 시 발생하는 결측치(NaN) 자동 제거.

### 리스크 관리 (`app/services/risk_manager.py`)
- **포지션 사이징**: 계좌 잔고 대비 최대 베팅 비중(기본 10%) 통제.
- **안전 장치**: 예수금 부족 또는 한도 초과 시 주문 차단.
- **청산 전략**: 진입가 대비 손절(2%), 익절(5%) 가격 자동 산출.

### 전략 엔진 (`app/services/trading_strategy.py`)
- **파이프라인**: 데이터 수집 -> TA-Lib 피처 생성 -> ML 예측 -> 리스크 검증 -> 주문 실행.
- **리팩토링**: 모듈화된 헬퍼 클래스들을 사용하여 로직 분리.

### 테스트
- `tests/test_strategy.py`: 리스크 로직 및 피처 생성 기능에 대한 단위 테스트 작성.

## 상태
- **전략**: 고도화 완료 (리스크 관리 + ML 예측 + 기술적 지표).
- **의존성**: Python 3.14 지원 TA-Lib 적용 완료.
